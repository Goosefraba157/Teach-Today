# Private Local Intake

This folder is for temporary, local source material that may contain student information, such as rosters, assessment spreadsheets, screenshots, PDFs, or exports.

- Files placed here are ignored by Git and must never be forced into a commit.
- Keep only what is needed for the active task.
- Prefer first name plus last initial for display and keep permanent IDs private.
- Before an import, review field mappings, destination school year/group, duplicate matches, and record counts.
- Preserve the source until the import is verified; then remove it according to school retention policy.
- Do not store passwords, access tokens, recovery codes, or Firebase credentials here.

Chat attachments can also be used as temporary input. They must follow the same rules and must not be copied into tracked folders.
