# Home navigation artwork

Lossless WebP crops from the teacher-approved generated sidebar reference, selected on 2026-10-30. These decorative fragments contain no student names, roster records, or assessment data. They are presentation assets only.

Source: built-in ImageGen reference `exec-4ba8c569-6c51-47fc-9558-413ec15e2488.png` from this design conversation. The full source remains in the local generated-image library, rather than the runtime repository. No new image generation or student attachment copying was required for extraction.

| Asset | Native size | Source crop (left, top, right, bottom) | Use |
| --- | --- | --- | --- |
| `lesson-binder.webp` | 318 × 97 | 390, 407, 708, 504 | Right-hand decorative open binder with structured, gray-banded lesson-plan pages. |
| `charting-paper.webp` | 254 × 100 | 456, 677, 710, 777 | Right-hand chart sheet with varied gray-shaded cell columns. |
| `profile-circles.webp` | 224 × 62 | 462, 891, 686, 953 | Four circles in one horizontal row: red, orange, yellow, green. |

The assets intentionally preserve the soft, low-contrast approved style and warm paper backgrounds. Keep actual menu labels as accessible live text above the art. Recommended row-art height is 44px; binder and chart may extend behind the end of a label, provided the label stays readable. Do not stretch the aspect ratio or interpret these illustrative motifs as student status values.

Extraction used FFmpeg image cropping and lossless WebP encoding. Every final crop was visually inspected for unwanted menu lettering or private content.

Records uses the MIT-licensed Bootstrap Icons v1.11.3 `floppy.svg` from https://github.com/twbs/icons/blob/v1.11.3/icons/floppy.svg, stored in assets/home-icons with the existing Bootstrap license. It is a standard icon, also reused as a faint decorative watermark.
