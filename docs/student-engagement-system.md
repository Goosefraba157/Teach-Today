# Student Engagement System

## Purpose

The engagement system should help students persist through difficult reading and spelling practice. Motivation should increase effort and repetition while keeping the instructional skill visible to the teacher.

## Engagement Is Not Mastery

Rewards can celebrate:

- Effort
- Completion
- Accuracy improvements
- Repeated practice
- Persistence after errors
- Returning to weak skills

Rewards must not automatically advance a student to a new step or substep.

## Student Identity

Use privacy-protective identity patterns:

- Nicknames instead of full names in student-facing views
- Avatars instead of student photos by default
- Class-safe display names
- Teacher-controlled roster identity

## Motivation Mechanics

V2 can support:

- Avatars
- Quests
- Skill paths
- Badges
- Challenge rounds
- Streaks
- XP or effort points
- Unlockable visuals
- Practice goals
- Class-safe celebrations

Each mechanic should be connected to instructional practice, not just screen time.

## Quest Structure

Quests should map to lesson assignments or skill goals:

- Sound-symbol quest
- Word building quest
- Word reading quest
- Dictation quest
- High frequency word quest
- Fluency quest
- Vocabulary quest
- Comprehension quest

Each quest should save evidence that the teacher can review.

## Feedback Rules

Student feedback should be:

- Immediate
- Encouraging
- Specific enough to guide correction
- Brief enough to keep momentum
- Sensitive to repeated errors

When possible, feedback should help the student try again instead of simply marking failure.

## Teacher Visibility

Teachers should see:

- Student effort
- Accuracy
- Attempt count
- Hints used
- Error types
- Repeated weak patterns
- Activities completed
- Evidence that may affect mastery

The student sees a motivating journey. The teacher sees instructional evidence.
