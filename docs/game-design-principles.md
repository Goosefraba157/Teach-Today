# Game Design Principles

## Purpose

Teach Today games are instructional practice experiences. They should make difficult reading and spelling work more motivating, but every game must remain connected to the lesson plan and student evidence.

## Required Game Connections

Every game or activity must declare:

- Lesson ID
- Step and substep
- Lesson part or instructional block
- Skill type
- Decoding or encoding target
- Word pattern or concept
- Source item set
- Student attempt data
- Teacher review status
- Mastery impact

If a game cannot declare these fields, it should not affect progress or mastery.

## Core Game Loop

1. Teacher plans or assigns the skill.
2. Student plays an activity matched to that skill.
3. The activity records attempts, errors, time, and support level.
4. Student receives motivating feedback and rewards.
5. Teacher sees evidence and error patterns.
6. Mastery is updated only through defined rules and teacher-visible evidence.

## Design Rules

- Fun supports repetition, attention, and confidence.
- Points, badges, and streaks reward effort, not mastery by themselves.
- Mastery requires evidence across attempts.
- Decoding and encoding should both have strong game formats.
- Controlled word lists and taught patterns should drive item selection.
- Review items and trouble spots should appear intentionally.
- Games should expose error patterns, not hide them.
- Hints and scaffolds should be tracked.
- A student should be able to replay weak skills without feeling punished.
- Teacher override, pause, and repeat controls must always win over game progress.

## Student Experience

Students should experience:

- Clear goals
- Short rounds
- Immediate feedback
- Encouraging correction
- Visible progress
- Avatars, quests, badges, and challenge paths
- Practice that feels active instead of worksheet-like

## Teacher Experience

Teachers should be able to answer:

- What skill did this game practice?
- Which words, sounds, or patterns were attempted?
- What did the student miss?
- Was the error decoding, encoding, automaticity, fluency, vocabulary, or comprehension related?
- Does this evidence support moving forward, repeating, or reteaching?

## MVP Acceptance Rule

A game is V2-ready only when it is both fun for students and instructionally inspectable by teachers.
