# Art Direction

## Role of Art

Teach Today should feel polished, warm, motivating, and trustworthy. The student side can use characters, quests, badges, backgrounds, and reward visuals. The teacher side should stay calm, readable, and professional.

Art is not decoration only. It should help students feel progress, identity, challenge, and encouragement.

## Workflow

Codex should build:

- Clean UI structure
- Asset folders
- Reusable visual components
- Placeholder art slots
- Naming conventions
- Design tokens
- Responsive layouts
- Animation hooks

ChatGPT, designers, or dedicated generation workflows should create:

- Character art
- Avatar sets
- Mascots
- Animal logo concepts when needed
- Game backgrounds
- Reward visuals
- Lesson activity graphics
- UI theme ideas
- Icons and badges

## Asset Folder Direction

Use predictable folders such as:

- `assets/brand/`
- `assets/characters/`
- `assets/avatars/`
- `assets/backgrounds/`
- `assets/badges/`
- `assets/icons/`
- `assets/activity-art/`
- `assets/ui/`

## Naming Convention

Use clear, searchable names:

- `avatar-viking-reader-01.png`
- `badge-decode-accuracy-01.png`
- `background-word-builder-cove-01.png`
- `icon-dictation-review.svg`
- `activity-syllable-scoop-board-01.png`

## Placeholder Rules

Temporary placeholders are allowed, but they should be:

- Clearly named as placeholders
- Easy to replace
- Sized like the final asset
- Neutral and non-distracting
- Not treated as final product art

Avoid inventing low-quality visual systems directly in code when an asset slot and design spec would be better.

## UI Style Direction

- Teacher UI: clean, practical, fast, calm, and data-readable.
- Student UI: colorful, expressive, interactive, and reward-rich.
- Shared brand: friendly, capable, evidence-based, and polished.

## Accessibility Notes

- Do not bake critical text into images.
- Use readable contrast.
- Keep icons supported by labels or tooltips where needed.
- Avoid visual clutter during instruction.
- Make animations purposeful and reducible.
